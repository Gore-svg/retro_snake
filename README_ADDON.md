# retro_snake

A browser-based retro Snake game inspired by the classic monochrome mobile Snake games.

## Files

- `index.html` - game page
- `style.css` - retro LCD/Nokia-inspired visual styling
- `script.js` - game logic

## Controls

- W - Up
- A - Left
- S - Down
- D - Right
- Space - Start / Pause
- R - Restart

## Hosting

This is a static website, so it can be hosted directly with GitHub Pages.

Enable GitHub Pages for the repository and select the branch containing these files. The site will use `index.html` as its entry page.
